# 综合经营分析指标 - API接口文档（前端专用）

## 1. 总览指标查询接口

### 接口基本信息

- **接口名称**: 总览指标查询
- **接口地址**: `/dashboard/business-analysis/overview`
- **请求方法**: POST
- **功能描述**: 提供整体经营状况概览，支持同比环比分析

### 请求参数

**BusinessOverviewQueryDTO**

| 字段名    | 类型   | 必填 | 描述     | 示例值       | 校验规则                                    |
| --------- | ------ | ---- | -------- | ------------ | ------------------------------------------- | ------------ |
| endDate   | String | 是   | 终止日期 | "2026-06-23" | @Pattern(regexp = "^\\d{4}-\\d{2}-\\d{2}$") |
| dimension | String | 是   | 维度     | "业务维度"   | @NotBlank, @Pattern(regexp = "^(业务维度    | 财务维度)$") |

### 响应结果

**BusinessOverviewVO**

| 字段名       | 类型                           | 描述             | 示例值 |
| ------------ | ------------------------------ | ---------------- | ------ |
| overviewData | List\<BusinessOverviewItemVO\> | 总览指标数据列表 | 见下方 |

**BusinessOverviewItemVO**

| 字段名          | 类型       | 描述     | 示例值   |
| --------------- | ---------- | -------- | -------- |
| indicatorType   | String     | 指标类型 | "EVA"    |
| actualValue     | BigDecimal | 实际值   | 10000.00 |
| dayOverDay      | BigDecimal | 比上日   | 100.00   |
| monthOverMonth  | BigDecimal | 比上月   | 500.00   |
| monthGrowthRate | BigDecimal | 环比增幅 | 0.05     |
| yearOverYear    | BigDecimal | 比同期   | 1000.00  |
| yearGrowthRate  | BigDecimal | 同比增幅 | 0.10     |
| completionRate  | BigDecimal | 完成率   | 0.85     |

### 接口说明

- **完成率计算**: 实际值/预算目标，预算目标为空时显示"-"
- **同比环比计算**: 在应用层根据输入日期计算
- **日期处理**: 输入日期为业务日期，查询该日期的指标数据

## 2. 图表指标查询接口

### 接口基本信息

- **接口名称**: 图表指标查询
- **接口地址**: `/dashboard/business-analysis/chart`
- **请求方法**: POST
- **功能描述**: 支持趋势分析，提供柱状图数据

### 请求参数

**BusinessChartQueryDTO**

| 字段名        | 类型   | 必填 | 描述     | 示例值       | 校验规则                                    |
| ------------- | ------ | ---- | -------- | ------------ | ------------------------------------------- | ------------ |
| endDate       | String | 是   | 终止日期 | "2026-06-23" | @Pattern(regexp = "^\\d{4}-\\d{2}-\\d{2}$") |
| dateDimension | String | 是   | 日期维度 | "月"         | @NotBlank, @Pattern(regexp = "^(日          | 月)$")       |
| dimension     | String | 是   | 维度     | "业务维度"   | @NotBlank, @Pattern(regexp = "^(业务维度    | 财务维度)$") |

### 响应结果

**BusinessChartVO**

| 字段名    | 类型                      | 描述         | 示例值 |
| --------- | ------------------------- | ------------ | ------ |
| chartData | List<BusinessChartItemVO> | 图表数据列表 | -      |

**BusinessChartItemVO**

| 字段名        | 类型       | 描述     | 示例值       |
| ------------- | ---------- | -------- | ------------ |
| indicatorType | String     | 指标类型 | "EVA"        |
| dataDate      | String     | 数据日期 | "2026-06-23" |
| actualValue   | BigDecimal | 实际值   | 10000.00     |

### 接口说明

**日期范围处理逻辑**:

- 按月查询：输入2026-06-23，返回2026年1-5月月末 + 2026年6月23日 + 2025年1-6月月末
- 按日查询：输入2026-06-23，返回2026年6月1-23日 + 2025年6月1-23日

## 3. 收益率查询接口

### 接口基本信息

- **接口名称**: 收益率查询
- **接口地址**: `/dashboard/business-analysis/yield`
- **请求方法**: POST
- **功能描述**: 投资绩效分析，支持本币投资/本币交易收益率

### 请求参数

**BusinessYieldQueryDTO**

| 字段名  | 类型   | 必填 | 描述     | 示例值       | 校验规则                                    |
| ------- | ------ | ---- | -------- | ------------ | ------------------------------------------- |
| endDate | String | 是   | 终止日期 | "2026-06-23" | @Pattern(regexp = "^\\d{4}-\\d{2}-\\d{2}$") |

### 响应结果

**BusinessYieldVO**

| 字段名             | 类型       | 描述                 | 示例值     |
| ------------------ | ---------- | -------------------- | ---------- |
| type               | String     | 收益率类型           | "本币投资" |
| yield              | BigDecimal | 收益率               | 0.035      |
| baseline           | BigDecimal | 基准收益率           | 0.030      |
| bpsOverBaseline    | BigDecimal | 跑赢基准值           | 50.00      |
| yearOverYear       | BigDecimal | 比去年同期收益率差值 | 10.00      |
| baselineDifference | BigDecimal | 比基准收益率差值     | 5.00       |

### 接口说明

- **收益率类型**: 本币投资/本币交易
- **单位说明**: 收益率为百分比格式，跑赢基准值为bps

## 4. 环形图指标查询接口

### 接口基本信息

- **接口名称**: 环形图指标查询
- **接口地址**: `/dashboard/business-analysis/donut`
- **请求方法**: POST
- **功能描述**: 业务结构分析，支持6种环形图类型

### 请求参数

**BusinessDonutQueryDTO**

| 字段名        | 类型   | 必填 | 描述     | 示例值       | 校验规则                                    |
| ------------- | ------ | ---- | -------- | ------------ | ------------------------------------------- | ------------ | ------- | ---------- | -------------------- | ----------- |
| endDate       | String | 是   | 终止日期 | "2026-06-23" | @Pattern(regexp = "^\\d{4}-\\d{2}-\\d{2}$") |
| dimension     | String | 是   | 维度     | "业务维度"   | @NotBlank, @Pattern(regexp = "^(业务维度    | 财务维度)$") |
| indicatorType | String | 是   | 指标类型 | "EVA"        | @NotBlank, @Pattern(regexp = "^(EVA         | 自营EVA      | 代客EVA | 营业净收入 | 账面非息（科目口径） | OCI估值)$") |

### 响应结果

**BusinessDonutVO**

| 字段名         | 类型       | 描述         | 示例值     |
| -------------- | ---------- | ------------ | ---------- |
| category1      | String     | 指标一级分类 | "EVA分类1" |
| category2      | String     | 指标二级分类 | "EVA分类2" |
| indicatorValue | BigDecimal | 指标值       | 10000.00   |

### 环形图类型说明

#### EVA环形图

- 指标一级分类：EVA<分类1>
- 指标二级分类：EVA<分类2>
- 指标值：实际数值

#### 自营EVA环形图

- 指标一级分类：EVA<分类1>
- 指标二级分类：EVA<分类2>
- 指标值：实际数值

#### 代客EVA环形图

- 指标一级分类：管理子团队
- 指标值：实际数值

#### 营业净收入环形图

- 指标一级分类：管理团队<内部>
- 指标值：实际数值

#### 账面非息（科目口径）环形图

- 指标一级分类：账面非息<业务类型1>
- 指标二级分类：账面非息<业务类型2>
- 指标值：实际数值

#### OCI估值环形图

- 指标一级分类：OCI指标<业务品种>
- 指标二级分类：OCI指标<剩余期限>
- 指标值：实际数值

### 接口基本信息

- **接口地址**: `/dashboard/business-analysis/table`
- **请求方法**: POST
- **功能描述**: 明细数据分析，支持多级分类和多种对比指标

| endDate       | String | 是   | 终止日期 | "2026-06-23" | @Pattern(regexp = "^\\d{4}-\\d{2}-\\d{2}$") |
| dimension     | String | 是   | 维度     | "业务维度"   | @NotBlank, @Pattern(regexp = "^(业务维度    | 财务维度)$") |
| indicatorType | String | 是   | 指标类型 | "EVA"        | @NotBlank, @Pattern(regexp = "^(EVA         | 自营EVA      | 代客EVA | 营业净收入 | 账面非息（科目口径） | OCI估值)$") |

### 响应结果

**BusinessTableVO**

| 字段名    | 类型                      | 描述         | 示例值 |

| 字段名          | 类型       | 描述         | 示例值     |
| --------------- | ---------- | ------------ | ---------- |
| category1       | String     | 指标一级分类 | "EVA分类1" |
| category2       | String     | 指标二级分类 | "EVA分类2" |
| category3       | String     | 指标三级分类 | "EVA分类3" |
| actualValue     | BigDecimal | 实际值       | 10000.00   |

| nonInterest     | BigDecimal | 非息         | 3000.00    |
| netInterest     | BigDecimal | 净息         | 7000.00    |
| completionRate  | BigDecimal | 完成率       | 0.83       |
| dayOverDay      | BigDecimal | 比上日       | 100.00     |
| monthOverMonth  | BigDecimal | 比上月       | 500.00     |
| yearOverYear    | BigDecimal | 比去年同期   | 1000.00    |
| monthGrowthRate | BigDecimal | 环比增长率   | 0.05       |

### 表格类型说明

#### EVA表格（包含自营代客）

- 字段：指标一级分类、指标二级分类、净息、非息、实际值、预算目标、完成率、比上日、比上月、比去年、环比增长率、同比增长率

#### 自营EVA表格

- 字段：指标一级分类、指标二级分类、净息、非息、实际值、预算目标、完成率、比上日、比上月、比去年、环比增长率、同比增长率

#### 代客EVA表格/营业净收入表格

- 字段：指标一级分类、指标二级分类、净息、非息、实际值、预算目标、完成率、比上日、比上月、比去年、环比增长率、同比增长率

#### 账面非息(科目口径)表格

- 字段：指标一级分类、指标二级分类、指标三级分类、实际值、比上日、比上月、比去年、环比增长率、同比增长率

#### OCI表格

- 字段：指标一级分类、指标二级分类、实际值、比上日、比上月、比去年、环比增长率、同比增长率

### EVA数据合并处理说明

当查询EVA指标类型时，后端会合并两组数据：

- 基础EVA数据
- 自营EVA/代客EVA组合数据

前端无需处理此逻辑，后端会自动合并返回完整数据。

## 接口调用规范

### 请求格式

- 所有接口统一使用POST请求
- 请求路径前缀：`/dashboard/business-analysis`
- 请求参数统一使用JSON格式

### 响应格式

- 统一使用`BeeResponseBody`注解处理响应
- 成功响应包含业务数据
- 错误响应包含错误码和错误信息

### 参数校验

- 使用JSR-303注解进行参数校验
- 必填字段使用`@NotBlank`或`@NotNull`注解
- 取值范围使用`@Pattern`注解限制取值

### 错误处理

- 参数校验失败返回400错误
- 业务逻辑异常返回500错误
- 数据不存在返回404错误

## 前端使用建议

### 1. 日期格式

- 所有日期参数使用"YYYY-MM-DD"格式
- 后端会自动处理日期范围计算

### 2. 维度选择

- 维度参数支持"业务维度"和"财务维度"
- 根据业务场景选择合适的维度

### 3. 指标类型

- 环形图和表格接口支持6种指标类型
- 根据展示需求选择合适的指标类型

### 4. 数据展示

- 图表数据支持按日期维度（日/月）查询
- 表格数据支持多级分类展示
- 所有数据都包含同比环比对比信息
