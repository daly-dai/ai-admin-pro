# 连云港古树打卡 · 点位初筛清单

> 筛选标准：**年限够老（≥500 年，优先千年+）** + **具有观赏性**（季节景观 / 树形 / 出片度 / 故事性）
> 状态说明：本清单为桌面初筛，树龄口径来自公开报道（不同年份口径有差异），**均需实地核实**（挂牌树龄、坐标、可达性、最佳观赏期照片）。

## 0. 数据底账

- 全市古树名木：536 株（2017）→ 715 株（"一树一策户口簿"）→ **718 株（2024）**，其中 500 年以上 63 株（2017 口径）
- 入选"中华古树名木"6 棵（2006 年，全国绿化委）：东磊延福观"玉兰四皇"4 株 + 孔望山龙洞庵宋代糯米茶 1 株 + 中云林场 800 年银杏 1 株

## 5. 待办清单

1. 实地核实：每棵树的**挂牌树龄、GPS 坐标、可达性、现状照片**（重点：云龙涧、东磊、龙洞庵、三元宫）
2. 统一树龄口径：同一棵树不同报道差异大（如玉兰"800+/1100+"、中云银杏"800~1000"），以官方挂牌/最新权威口径为准
3. 与市自然资源和规划局 / 园林部门确认**名录授权与数据来源**
4. 每个点位标注**最佳观赏期**：春季（玉兰、糯米茶花开）与秋季（银杏黄金甲）双季错峰
5. 从 718 株名录中按"500 年以上 + 可达 + 观赏性"继续扩充到 30~50 棵目标池
