## 基本描述

**一句话描述**：运营/业务人员管理「邮件模板」（每模板含名称/收件人/抄送/富文本正文，正文内嵌 `{{table}}` 占位符），每个模板下挂多个「报表」文件（用户上传的 .xlsx，概念上存于该模板在在线文档平台的专属文件夹）；用户在平台内在线编辑报表后点「发布」拿到最新文件，再点「预览结合效果」把报表表格注入正文进行整封邮件的微调与发送。

**为什么需要**：真实业务中报表数据由专业的在线文档平台维护（表格样式、专业排版），邮件需要把"模板正文 + 报表表格"结合成可发送的成品邮件。本次是讲解用 Demo：在线文档平台与邮件后端**尚未真实存在**，需要前端把完整链路（管理 → 在线编辑 → 发布 → 预览微调 → 发送）用 mock 走通，验证交互与样式，供后端接入时参考。

**本期边界**：纯前端 Demo。不做真实发信、不做真实在线文档平台对接、不做模板持久化到服务端（localStorage 持久化、刷新不丢）；报表一律**用户上传**（无预置/一键生成）。

## 核心概念与总体架构

```
┌─ 页面层 ──────────────────────────────────────────────┐
│ 模板列表页 /mail/template（CRUD）                      │
│ 工作台（详情）页 /mail/template/:id                    │
│   ├ 顶部信息条（SDetail 紧凑，正文省略行 hover 全文）   │
│   ├ 报表区：左列表（含演示权限折叠）+ 右（平铺/iframe） │
│   └ 「预览结合效果」→ 预览抽屉（微调 + 发送）          │
│ mock 在线编辑平台页（内部路由，被 iframe 嵌入）        │
└──────────────────────┬────────────────────────────────┘
                       │ postMessage（模拟跨域平台通信）
┌─ service 层（按真实后端形状设计）──────────────────────┐
│ 模板 CRUD / 报表列表·上传·保存 / 邮件发送              │
│ └ mock 实现：Promise 延迟 + localStorage（可整体替换） │
└──────────────────────┬────────────────────────────────┘
                       │
┌─ 渲染内核（v1 已验证，原样复用 + 扩展）────────────────┐
│ excel→邮件安全 HTML（样式保真 / 网格线兜底 / 内容边界）│
│ exceljs 写回：编辑值回写原 workbook → 重新导出（新增） │
└────────────────────────────────────────────────────────┘
```

- **报表 = 模板专属文件夹内的文件**（真实系统语义：新建模板时后端在在线文档平台建对应文件夹，报表增删改查都落在该文件夹；Demo 中以 mock 数据表达，模板删除连带删除其全部报表）。
- **在线编辑 = 切换 iframe 地址**：同一报表有阅读模式（`?mode=read`）与编辑模式（`?mode=edit`）两种嵌入地址，前端切换地址即切换模式，无独立页面跳转。
- **权限语义**（按接口与平台拦截行为表达，见「权限模型」）：报表列表只返回有查看权限的文件；无编辑权限时点编辑，平台侧（iframe 内）报错拦截。

## 使用流程（主链路）

1. 进入「邮件工具 → 邮件模板」列表页：模板列表（初始预置 1 个示例模板，不含报表，可删除）；可新增/编辑/删除模板，点「进入」打开工作台。
2. **新增模板**（弹窗表单）：填名称（=邮件主题）、收件人（必填，可多人）、抄送（可选）；收件人/抄送均为**通讯录多选**（下拉项含组织路径 `officeOrgPath` + 用户标识 `userInfo`，如 张三/112233，页面不展示邮箱）；正文从 2 套预设中选择一套预填富文本编辑器（预设均恰好含 1 个 `{{table}}`）；保存校验：收件人 ≥1 人、正文**恰好包含 1 个** `{{table}}`（0 个或缺省/≥2 个均阻止保存并提示）。
3. **进入工作台**：一体白面板顶部为**紧凑信息条**（SDetail：模板名称/收件人/抄送 一行三列 + 正文整行单行省略，hover 看完整富文本与占位符说明）。报表区无选中项：左侧报表列表（有权限的文件），右侧**全部报表平铺**（文件卡 = 文件类型图标 + 文件名称 + 最后更新时间）。
4. **报表为空时**：空态提示「暂无报表，上传 xlsx 开始演示」+ 上传入口。上传 xlsx：校验扩展名/大小/PK；与现有报表**同名 → 弹确认后覆盖**（替换文件内容、更新时间刷新，无版本历史）；异名 → 新增报表。上传入口同时位于左侧列表顶部（无文件夹权限时禁用 + tooltip 说明）。
5. 点击某报表文件卡 → 右侧切换为该报表 iframe **阅读模式**（左侧列表该项同步高亮）；iframe 上方工具栏：返回报表列表 / 报表名 / 阅读 ⇄ 编辑切换 / 发布（编辑模式可用）。点击「编辑」→ iframe 切换编辑地址。
   - 无编辑权限（只读）报表：「编辑」可点，但切换后 iframe 内显示**「无编辑权限」错误页**（平台拦截，非前端禁用）。
6. 编辑模式下在 mock 在线编辑器中**修改单元格值**（仅改值；样式来自原文件，编辑不破坏）；点「发布」：
   - mock 平台保存 + exceljs 把改动值**回写原 workbook 重新导出** xlsx 文件流 → 前端**存回报表**（覆盖存储，此后阅读/再预览均是最新内容；不触发浏览器下载）；
   - 发布成功 toast，页面顶部「预览结合效果」可用。
7. 点「预览结合效果」（顶部常驻按钮，默认使用当前选中/最近发布的报表，预览前可下拉切换其他有查看权限的报表）→ 打开**预览抽屉**：
   - 抽屉顶部只读展示 主题/收件人/抄送（取自模板）；
   - 信纸 = 模板正文 + 所选报表表格注入 `{{table}}` 后的**整封邮件**（保真渲染：样式 100% 来自文件，无边框边补网格线）；
   - 正文可点按微调；动作 = **发送**（主按钮，无保存、无下载/复制 HTML）。
8. 点「发送」→ 确认框（"将向 N 个收件人发送邮件，附件：xxx.xlsx"）→ mock 后端成功：toast + console 打印完整 payload（`to / cc / subject / bodyHtml / attachments[]`）→ 关闭抽屉回到工作台。模板与报表数据均不变（无保存语义）。

## 功能清单

### 功能一：模板管理（列表 CRUD）

| 项     | 说明                                                                                                                         |
| ------ | ---------------------------------------------------------------------------------------------------------------------------- |
| 列表页 | STable：模板名称 / 收件人 / 抄送 / 报表数 / 更新时间 / 操作（编辑、删除、进入工作台）；支持按名称搜索；初始预置 1 个示例模板 |
| 新增   | 弹窗表单（同组件复用于编辑）：名称、收件人、抄送、正文（预设选择 + 富文本编辑器）                                            |
| 编辑   | **仅列表页操作列**入口（不做独立编辑页，工作台内不提供模板编辑）                                                             |
| 删除   | 确认后删除模板，**连同其文件夹与全部报表 mock 数据**                                                                         |

字段与校验：

| 字段     | 类型                 | 必填 | 校验/说明                                                                                                                |
| -------- | -------------------- | ---- | ------------------------------------------------------------------------------------------------------------------------ |
| 模板名称 | string               | 是   | 即邮件主题，单字段                                                                                                       |
| 收件人   | 通讯录多选           | 是   | 用户下拉多选（接口项：`officeOrgPath` 组织路径 + `userInfo` 用户标识，如 张三/112233）；提交传 userInfo（对外=逗号分隔串），真实后端按 userInfo 换邮箱；≥1 人 |
| 抄送     | 通讯录多选           | 否   | 同上；可为空                                                                                                             |
| 正文     | 富文本 HTML          | 是   | 预设 2 套正文模板可选（新增时选择后预填）；保存校验：**恰好 1 个** `{{table}}`                                           |

> 修订：收件人/抄送全模块（列表页/基础信息卡/预览抽屉顶部等所有展示处）只出现用户信息（userInfo/组织路径），**不展示邮箱**——邮箱由真实后端按 userInfo 解析，Demo 无邮箱概念。

### 功能二：工作台（详情）页

> 修订（Task 4 走查）：顶部由「大折叠卡」改为**紧凑信息条**——整页收敛为**一体白面板**：顶部信息条（SDetail）+ 下方左右分栏（左报表列表 | 右内容，1px 边框分隔，不再有两张悬浮卡的模糊感）；权限演示开关从报表行内**移入左栏底部默认折叠的「演示权限」面板**，报表行回归干净（图标/名称/时间 + hover 删除 + 选中高亮）。

- **顶部信息条**：SDetail 紧凑展示（只读、无编辑入口）：模板名称 / 收件人 / 抄送 一行三列 + **正文占整行单行省略**（摘要为纯文本，hover 展示完整富文本，占位符替换说明并入 hover 提示）；更新时间以模板名称旁小字展示。
- **报表区（左）**：报表列表项 = 文件图标 + 名称 + 最后更新时间；当前选中/正在查看的报表**高亮**；列表头部「上传报表」按钮；报表项删除（确认）为行内 hover 显现；**权限演示开关收进底部折叠面板**（见功能五）。
- **报表区（右）**：
  - 默认（未选中）：**全部报表平铺**为文件卡（图标 + 名称 + 更新时间，只读角标若适用）；
  - 点击文件卡：整区切换为该报表 iframe（阅读模式）；
  - iframe 工具栏：返回报表列表 / 报表名 / 阅读 ⇄ 编辑 / 发布（编辑模式可用）。

### 功能三：报表与上传

- 报表 = 模板文件夹内文件，仅归属当前模板（不跨模板共享）。
- 上传：`.xlsx`（校验扩展名 / ≤10MB / PK 文件头）；**同名 → 确认框（"覆盖将替换原内容且不可恢复"）→ 覆盖**；异名 → 新增；上传者视角默认可编辑。
- 无上传（文件夹）权限：上传按钮禁用 + tooltip / 上传被拦截提示。
- 空态：新模板无报表时右侧显示"暂无报表，上传 xlsx 开始演示"。
- 删除报表 = 删除文件夹内文件（确认后删除；讲解时注意保护用户原文件——Demo 存的是副本）。

### 功能四：mock 在线编辑平台（iframe）

- 平台为**本地 mock 页**（应用内独立路由），父页面以 iframe 嵌入，通信走 **postMessage**（协议见「postMessage mock 协议」），模拟真实跨域平台。
- 阅读模式（`?mode=read`）：解析报表 xlsx → 只读表格渲染（沿用 excel→html 保真渲染或等价的只读表格）。
- 编辑模式（`?mode=edit`）：解析报表 xlsx → **可编辑表格，仅单元格值可改**（文本/数字）；不做增删行列、不做样式编辑——发布时 exceljs 把改动值写回**原 workbook 对应单元格**再重新导出，原字体/边框/底色/列宽等样式 100% 保留。
- 无编辑权限：切编辑模式时 iframe 内显示「无编辑权限」错误页（拦截形态，由 mock 平台按报表权限判定）。

### 功能五：权限模型（接口语义 + demo 呈现）

| 权限         | 载体（mock 字段）  | 语义                                                 | Demo 呈现                                                                  |
| ------------ | ------------------ | ---------------------------------------------------- | -------------------------------------------------------------------------- |
| 文件夹权限   | 模板级 `canUpload` | 无权限则不能新增报表                                 | 上传按钮禁用 + tooltip                                                     |
| 报表查看权限 | 报表级 `canView`   | **接口不返回无查看权限的文件**——列表只见有权限的报表 | 「演示权限」面板「无查看权限」开关，打开后该报表**从列表消失**（模拟接口过滤） |
| 报表编辑权限 | 报表级 `canEdit`   | 无编辑权限 = 只读：可阅读、可预览，但不能编辑        | 「演示权限」面板「仅查看」开关；**「编辑」仍可点**，iframe 内报「无编辑权限」 |

- 权限开关**收在左栏底部默认折叠的「演示权限」面板**（界面角落），并附「复位演示权限」按钮（被隐藏报表可从列表恢复）；驱动 service 层过滤与 iframe 拦截行为。

### 功能六：发布 → 预览结合 → 发送

| 动作     | 位置/时机              | 行为                                                                                                                                         |
| -------- | ---------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| 发布     | 编辑模式 iframe 工具栏 | mock 平台保存 + exceljs 回写导出 xlsx 文件流 → **存回报表**（覆盖存储、更新时间刷新）、不自动下载；成功 toast                                |
| 预览结合 | 页面顶部常驻按钮       | 默认用当前选中/最近发布的报表，可下拉切换（仅可查看的报表）；打开预览抽屉                                                                    |
| 微调     | 预览抽屉内             | 信纸正文可点按修改（含表格在内的成品所见即所得）                                                                                             |
| 发送     | 预览抽屉主按钮         | 确认框（收件人数 + 附件名）→ mock 后端发送：toast + console 完整 payload（`to / cc / subject / bodyHtml / attachments[]`）→ 关闭抽屉回工作台 |

- **无「保存」动作**：预览微调不写回模板/报表，发送后一切数据不变。
- 发送 payload 的附件 = 当前报表最新 xlsx（附件名 = 报表名）。

### 功能七：渲染内核（v1 继承 + 扩展）

预览/发送的表格渲染沿用 v1 已验证规则（详见「边界和约束」中保真清单）：

- 颜色 100% 忠于文件字节（含刻意低对比组合），**不做任何可读性改写**；
- 无边框边补 Excel 观感浅灰网格线（显式边框优先）——渲染层唯一允许的加料；
- 按内容边界裁掉尾部空行/空列（样式残留不影响范围）；
- 主题色按 Excel 索引约定解析（0=lt1 白 / 1=dk1 黑 / 2=lt2 / 3=dk2，accent1-6 对齐）；indexed 完整 64 色调色板；
- 产出邮件安全 HTML（仅 table/tr/td + 内联样式）；
- **新增**：exceljs 写回路径（编辑值 → 原 workbook → writeBuffer → base64 存回），保证在线编辑后样式不丢。

## 数据模型（mock，localStorage）

```ts
// 模板（含"文件夹"概念）
interface MailTemplate {
  id: string;
  name: string; // = 邮件主题
  recipients: string[]; // 收件人：通讯录多选 userInfo（形如 张三/112233），真实后端按 userInfo 换邮箱
  cc: string[]; // 抄送：同上 userInfo 列表，可为空
  bodyHtml: string; // 富文本正文（恰好含 1 个 {{table}}）
  presetId?: string; // 创建时选择的预设
  canUpload: boolean; // 文件夹权限（演示）
  updatedAt: number;
}

interface Report {
  id: string;
  templateId: string;
  name: string; // 含 .xlsx 扩展名；附件名 = 报表名
  type: 'xlsx';
  fileBase64: string; // 最新 xlsx（发布后为回写导出结果）
  canView: boolean; // false → service 层不返回（列表消失）
  canEdit: boolean; // false → 只读，iframe 编辑报无权限
  updatedAt: number;
}

interface SendMailPayload {
  to: string[]; // 收件人 userInfo 列表（真实后端解析换邮箱后发信）
  cc: string[]; // 抄送 userInfo 列表
  subject: string; // = 模板名
  bodyHtml: string; // {{table}} 已替换为所选报表保真表格
  attachments: { name: string; content: string /* base64 xlsx */ }[];
}
```

存储：localStorage（模板记录 + 报表元数据 + xlsx 转 base64 文件体）；单文件超过 ~2MB 时提示改用小文件（演示用 exceljs 导出/上传的文件通常远小于该值）。

## 接口（service 层，按真实后端形状）

> Demo 实现 = 方法签名与真实后端一致 + Promise 延迟 + localStorage 存取 + 权限过滤。接真实后端时只替换实现。

| 方法                              | 语义                                                                 |
| --------------------------------- | -------------------------------------------------------------------- |
| `getTemplateListByPost(query)`    | 模板分页列表（名称搜索）                                             |
| `createTemplateByPost(data)`      | 新建模板（真实系统：后端同时在在线文档平台建文件夹）                 |
| `updateTemplateByPost(data)`      | 编辑模板                                                             |
| `deleteTemplateByPost(id)`        | 删除模板（连带删除其文件夹/报表）                                    |
| `getReportListByPost(templateId)` | 报表列表——**只返回 canView 的文件**                                  |
| `uploadReportByPost(...)`         | 上传 xlsx；同名需带覆盖确认标识（前端先查重再确认）                  |
| `downloadReportByPost(reportId)`  | 获取报表文件（xlsx 流/base64，供阅读模式与预览使用）                 |

## postMessage mock 协议（父页面 ⇄ mock 在线编辑 iframe）

| 方向  | 消息                                                 | 说明                                     |
| ----- | ---------------------------------------------------- | ---------------------------------------- |
| 父→子 | `{type:'init', reportId, fileBase64, mode, canEdit}` | 加载时下发报表文件与模式、权限           |

## 状态与规则（关键约束）

| 规则           | 处理                                                                                                              |
| -------------- | ----------------------------------------------------------------------------------------------------------------- |
| 正文占位符个数 | 新增/编辑保存时校验**恰好 1 个** `{{table}}`：0 个 → 提示"正文必须包含占位符"；≥2 个 → 提示"不允许存在多个占位符" |
| 同名上传       | 先查重 → 确认框 → 覆盖（替换文件、刷新更新时间、无版本历史）                                                      |
| 删除模板       | 确认框 → 模板 + 文件夹 + 全部报表一并删除                                                                         |
| 无查看权限报表 | 不出现在任何列表/下拉（service 过滤）；demo 开关驱动                                                              |
| 只读报表       | 阅读正常；「编辑」可点但 iframe 报「无编辑权限」；预览下拉可选                                                    |
| 发布           | 仅编辑模式可用；发布后存回报表，预览自动就绪；不自动下载                                                          |
| 预览报表选择   | 仅可查看报表可选；默认当前选中/最近发布                                                                           |
| 发送后         | toast + console payload；关抽屉回工作台；模板与报表数据不变                                                       |
| 渲染加料       | 仅网格线兜底一项；颜色等一律忠于文件，不做可读性改写（v1 已确认）                                                 |

## 边界和约束

- **能做什么**：模板 CRUD（列表 + 弹窗表单 + 搜索）；工作台（只读基础卡 + 报表列表/平铺/选中高亮 + iframe 阅读/编辑切换）；报表上传/覆盖/删除（空态引导）；mock 在线编辑（单元格值编辑 + exceljs 回写样式保真 + postMessage 模拟平台）；权限三种拦截（上传禁用 / 只读 iframe 报错 / 无查看列表过滤）的讲解演示；发布（保存导出回存）；预览结合（保真表格注入 + 正文微调）；mock 发送（确认框 + payload）。
- **不能做什么**：真实发信；真实在线文档平台对接；服务端持久化；`.xls` 等非 xlsx 格式；多 `{{table}}` 占位/编号插槽（v2 明确单占位）；单元格之外的编辑（增删行列/改样式——那是真实平台能力，非本 demo mock 范围）；邮件合并（每行一封）；预览后保存/草稿；下载/复制 HTML。
- **渲染内核约束（继承 v1）**：≤10MB、500 行 × 60 列截断（可提示）；样式降级一律进 warnings 明示，唯一例外为网格线兜底；主题色非 Office 主题按默认 12 色近似（含 WPS accent1/5 顺序差异）。
- **已知取舍**：iframe 内容为 mock 平台渲染，不等于真实平台；发布回写仅覆盖"值"，平台侧的样式编辑能力不在 mock 范围；localStorage 容量限制（>~2MB 提示换小文件）。
